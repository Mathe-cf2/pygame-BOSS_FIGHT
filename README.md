## 🌌 Sobre o projeto

**BOSS FIGHT: NEON APOCALYPSE** é um jogo de ação e sobrevivência espacial desenvolvido em Python utilizando a biblioteca Pygame.

O jogador controla uma nave em um ambiente futurista com estética neon, enfrentando diferentes tipos de inimigos e chefes. A cada nova fase, a dificuldade aumenta, exigindo estratégia, reflexos e habilidade para sobreviver.

## ✨ Funcionalidades

- 🚀 Movimentação da nave do jogador.
- 🔫 Sistema de disparos e projéteis.
- 👾 Três tipos de mini-bosses: Drone, Destroyer e Hunter.
- 👑 Boss principal desbloqueado após derrotar os mini-bosses.
- 📈 Dificuldade progressiva a cada fase.
- ❤️ Sistema de vida e dano.
- ⚡ Power-ups: tiro triplo, tiro rápido, escudo e recuperação de vida.
- 🏆 Sistema de pontuação.
- 🔄 Reinício após Game Over.
- 🌃 Interface com identidade visual neon.

## 🎮 Controles

| Tecla | Ação |
|---|---|
| `W` / `↑` | Mover para cima |
| `S` / `↓` | Mover para baixo |
| `A` / `←` | Mover para esquerda |
| `D` / `→` | Mover para direita |
| `ESPAÇO` | Atirar |
| `R` | Reiniciar após Game Over |
| `ESC` | Sair do jogo |

## 🛠️ Tecnologias utilizadas

- **Python 3**
- **Pygame**
- Programação Orientada a Objetos (POO)
- Manipulação de imagens e colisões
- Sistemas de dificuldade e progressão

## ⚙️ Como executar

**1. Clone o repositório:**

```bash
git clone https://github.com/SEU-USUARIO/BOSS_FIGHT.git
```

**2. Entre na pasta:**

```bash
cd BOSS_FIGHT
```

**3. Instale o Pygame:**

```bash
pip install pygame
```

**4. Execute o jogo:**

```bash
python main.py
```

> É necessário manter os arquivos de imagem e demais recursos dentro da pasta `assets` para o jogo funcionar corretamente.
